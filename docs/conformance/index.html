Conformance files

Small figure files, each made to pass or to break one rule of the profile, with the verdict a validator must give. Another implementation shows that it stores, finds and checks a declaration as the reference does by giving the same verdicts. The data is synthetic: a ramp with one bright spot, 40 by 60 values, noise-free. Anatomy of a UDeep file takes the two valid files apart.

The same cases in machine-readable form: expected.json. With the reference implementation, a case is checked as

import numpy, udeep.validate
report = udeep.validate.validate("valid.jpg", data=numpy.load("data.npy"), sdr="valid_sdr.png")
print(report)     # or report.status("data link"), report.ok

or, for a file on its own, python -m udeep.validate FILE. Points that need the figure itself (the pixels, §10 points 3 to 5) are not part of these cases.
